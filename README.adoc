= Quartus Prime Lite Installer

== Installation

=== Systemanforderungen

* *⚠️  MINDESTENS 35GB SPEICHERPLATZ*
* https://distrobox.it/#installation[`distrobox`]
** Am besten über den Paketmanager der jeweiligen Distribution installieren
** Falls eine Auswahl auftaucht, in der `podman` zur Wahl steht, `podman` auswählen

=== Konsole

. `+distrobox assemble create --file "https://codeberg.org/tobilinz/quartus-prime-lite-installer/raw/branch/main/distrobox.ini"+`
. `quartus-install`
. Den Anweisungen folgen

=== Optional: MIME-Unterstützung

Mit MIME-Unterstützung kannst du `.bdf` Dateien mit einem Doppelklick in Quartus öffnen.

Nachdem du Quartus erfolgreich auf deinem System installiert hast, führe folgenden Befehl in einem Host-Konsolenfenster aus:

  $HOME/.local/share/quartus-prime-lite-ubuntu/mime-install

== FAQ

=== Die Simulation gibt den Fehler `Error (suppressible): (vsim-12110)` aus

Im Simulationsfenster:

. `+Simulation > Simulation Settings+`
. `-suppress 12110` bei der Zeile, die mit `vsim` beginnt, anhängen.

=== Die Simulation gibt den Fehler `Error: Invalid license environment` aus

Im Hauptfenster von Quartus Prime Lite:

. In der oberen Toolbar `+Tools > License Setup..+` wählen
. Im `Options` Fenster, das sich geöffnet hat, folgendes tun:
** Häkchen bei `Automatically Refresh Server License Token` setzen
** `Get no-cost licenses` wählen, warten, Häkchen bei erster Lizenz im Pop-Up setzen, `Ok`

== Deinstallation

Führe folgenden Befehl in einem Host-Konsolenfenster aus:

  $HOME/.local/share/quartus-prime-lite-ubuntu/uninstall

Ohne diesen Befehl wird das Programm nicht vollständig vom System entfernt.
