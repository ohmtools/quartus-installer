= Quartus Installer

Dieses Projekt vereinfacht die Softwareinstallation und Nutzung von "Quartus Prime Lite".

Es richtet außerdem MIME-Unterstützung ein und behebt häufige Fehlerquellen, wie `-novopt` und falsche Simulationspfade.

== Installation

=== Voraussetzungen

* 35GB Speicherplatz (minimum 25GB)
* Irgendeine Linux-Distribution als Betriebssystem
* https://distrobox.it/#installation[`distrobox`]
** Am besten über den Paketmanager der jeweiligen Distribution installieren
** Falls eine Auswahl auftaucht, in der `podman` zur Wahl steht, `podman` auswählen

=== Konsole

. `+distrobox assemble create --file "https://codeberg.org/tobilinz/quartus-installer/raw/branch/main/distrobox.ini"+`
. `quartus-install`
. Den Anweisungen folgen
  * Studenten der TH-Nürnberg sollten mindestens `quartus,questa_fse,cyclone` installieren 

== Häufige Fehler

.*Lizenz fehlt*
[%collapsible]
====
Beispiele:

* `Error: Invalid license environment`
* `Error: Unable to obtain a license`
* `Error: Failure to obtain a Verilog simulation license`
* `Error: Failure to obtain a VHDL simulation license`

Im Hauptfenster von Quartus Prime Lite:

. In der oberen Toolbar `+Tools > License Setup..+` wählen
. Im `Options` Fenster, das sich geöffnet hat, folgendes tun:
** Häkchen bei `Automatically Refresh Server License Token` setzen
** `Get no-cost licenses` wählen, warten, Häkchen bei erster Lizenz im Pop-Up setzen, `Ok`
====

.*Simulationsfehler `+Line: 281bus_port->has_type()Stack Trace: 0x1610a: TBO_...+`*
[%collapsible]
====
Im Hauptfenster von Quartus Prime Lite:

* Bei den Verwendeten Inputs / Outputs im Schaltplan gibt es Lücken (z.B. LEDR[0..5] und LEDR[9] => Lücke von LEDR[6..8]). 
* Zum Beheben, Inputs / Outputs platzieren, die diese Lücken verwenden. 
* Die Inputs / Outputs dürfen auch an nichts angeschlossen sein.
====

.*Simulationsfehler `+Run Analysis and Synthesis ...+`*
[%collapsible]
====
Im Hauptfenster von Quartus Prime Lite:
----
  Processing > Start Compilation
----
====

.*Simulationsfehler `+Unable to open .../simulation/qsim/___.vwf.vt+`*
[%collapsible]
====
Im Dateimanager die Datei 

[subs="macros,quotes"]
----
pass:[+.../simulation/qsim/___.vwf.vt+*]*.vt*
----

zu
  
[subs="macros,quotes"]
----
+.../simulation/qsim/___.vwf.vt+
pass:[+.../simulation/qsim/___.vwf.vt+]
----

umbenennen.
====

== Upgrade

=== Voraussetzungen

* Der `home` Ordner des Containers wurde bei der Installation nicht geändert

=== Konsole (Host)
----
"${XDG_DATA_HOME:-$HOME/.local/share}/quartus-prime-lite/upgrade" quartus-prime-lite-ubuntu
----

== Deinstallation

=== Konsole (Host)
----
"${XDG_DATA_HOME:-$HOME/.local/share}/quartus-prime-lite/uninstall" quartus-prime-lite-ubuntu
----
